# 口播文案转插画提示词

将口播文案稿转化为插画的画面设计和生成提示词。

## 输入

口播文案稿（markdown格式），包含：
- 文案正文
- 节奏提示标注（如"停顿半秒"、"加重"、"摇头"等）- 可选
- 标题和话题标签 - 可选

## 输入验证

- 文案 < 100字：提示"文案太短，建议补充细节后再生成插画"
- 无明显场景转折：提取金句，生成1-2张金句画面
- 无节奏提示：忽略节奏，按内容分段

## 输出位置

默认输出到口播文案同级目录：
- 如果文案在 `myTarget/xxx.md`
- 输出到 `myTarget/baoyu/xxx/`

用户可通过参数自定义输出目录。

## 输出结构

```
{输出目录}/
├── 脚本剧情.md          # 画面设计文档
└── prompts/
    ├── 01-cover-*.md     # 封面/开头画面
    ├── 02-content-*.md   # 内容画面（可多个）
    └── NN-ending-*.md    # 结尾画面
```

## 工作流程

### Step 1：分析文案

读取口播文案，提取：
- **关键场景**：每个段落的核心画面
- **情绪转折点**：从好到坏、从期待到失望等
- **金句**：可独立成为画面的金句
- **对比轴**：任何对比关系（时间、空间、情绪、结果等）

### Step 2：设计画面

为每个关键场景设计插画画面，遵循以下原则：

**主角设定**：
- 默认使用橘猫（orange tabby cat）作为主角
- 用户可自定义动物类型（猫、狗、兔子、熊猫等）
- 服装和色调根据场景自动匹配：
  - 积极场景：暖色调（橙色、黄色、粉色）
  - 消极场景：冷色调（蓝色、灰色、暗色）
  - 工作场景：职业装/休闲装
  - 生活场景：家居服/外出服

**画面类型**：
- **对比画面**：左右分屏，强化情绪反差
- **动态画面**：用特效（火星、速度线）表现动作
- **情绪画面**：用表情和氛围传达感受
- **象征画面**：用视觉隐喻表现抽象概念

**文字处理**：
- 画面中的文字尽量短（1-2个字）
- 避免长句，降低AI生成时乱码风险
- 文字示例：对勾、靠谱、百万、订单：12、踏实、空虚

### Step 3：生成提示词

为每个画面生成中文提示词，格式：

```markdown
---
type: cover/content/ending
scene: 画面N-场景名称
layout: sparse/balanced/comparison
style: pop
---

# Prompt

[场景整体描述]

主角：
- [动物的动作、表情、服装]

[其他元素]：
- [道具、背景、特效等]

背景：
- [环境描述]

风格：
- [画面风格、色调、氛围]
- 画面填满整个画布，不留空白
```

**提示词要点**：
- 使用中文，便于理解和修改
- 描述具体、可视化
- 包含情绪和氛围描述
- 指定色调（暖色/冷色）

### Step 4：创建输出文件

1. **创建目录结构**：
   ```
   mkdir -p {输出目录}/prompts
   ```

2. **写入脚本剧情.md**：
   - 包含所有画面设计
   - 每个画面标注对应文案位置
   - 提供推荐组合方案（精简版/完整版/全量版）

3. **写入提示词文件**：
   - 每个画面一个独立文件
   - 命名格式：`NN-{type}-{scene}.md`

### Step 5：图片生成（可选）

生成提示词后，询问用户：
1. 是否立即生成图片？
2. 使用哪个后端？（baoyu-xhs-images / 其他）

如果用户确认，自动调用对应的图片生成工具。

## 画面数量建议

| 文案长度 | 建议画面数 | 说明 |
|---------|-----------|------|
| < 300字 | 3-4张 | 精简版，只保留核心转折 |
| 300-500字 | 5-6张 | 完整版，覆盖主要场景 |
| > 500字 | 7-8张 | 全量版，故事最完整 |

## 推荐组合模板

每个文案都提供三种组合方案：

**方案一：精简版（3张）**
1. 开头反差/钩子
2. 故事高潮/情绪转折
3. 核心金句/结尾

**方案二：完整版（5张）**
1. 开头
2. 前半段关键场景
3. 转折点
4. 后半段关键场景
5. 结尾

**方案三：全量版**
- 覆盖所有关键场景

## 风格参考

默认使用 `pop` 风格（活力、吸睛、色彩鲜艳），可根据用户需求调整：
- `cute`：甜美、少女风
- `warm`：温馨、生活感
- `minimal`：极简、高级感
- `sketch-notes`：手绘、笔记风

## 示例

### 示例1：职场对比主题

输入文案片段：
```
在阿里，我累瘫在椅子上长叹一声："终于完事了。"那一刻我很开心。
在国企，我也长叹一声，但我很憋屈。
```

输出画面设计：
```
## 画面 1：开头反差

**场景**：左右分屏对比
- 左边：橘猫穿格子衫，瘫在椅子上，眼睛有光，嘴角带笑
- 右边：同一只橘猫穿白衬衫，瘫在椅子上，眼神空洞，嘴角下垂

**对应文案**：在阿里，我累瘫在椅子上长叹一声："终于完事了。"那一刻我很开心。在国企，我也长叹一声，但我很憋屈。
```

输出提示词：
```
左右分屏对比插画，同一只橘猫的两种状态。

左边 - 深夜办公室：
- 橘猫穿着格子衫，瘫在办公椅上
- 眼睛有光，嘴角带笑，疲惫但满足
- 暖黄色调，温馨氛围

右边 - 白天办公室：
- 同一只橘猫穿白衬衫，瘫在椅子上
- 眼神空洞，嘴角下垂，无聊疲惫
- 冷蓝色调，压抑氛围

风格：可爱卡通插画，线条清晰，色彩鲜艳，表情丰富。
```

### 示例2：情感成长主题

输入文案片段：
```
以前我总觉得，一个人扛着才是坚强。
后来我才明白，愿意开口求助，才是真正的勇敢。
```

输出画面设计：
```
## 画面 1：独自扛着

**场景**：橘猫一个人搬箱子，摇摇欲坠
- 橘猫表情倔强，咬牙坚持
- 箱子堆得很高，快要倒了
- 周围没有其他人

## 画面 2：开口求助

**场景**：橘猫和朋友一起搬箱子，轻松愉快
- 橘猫表情放松，微笑
- 朋友帮忙分担
- 温暖的氛围
```

### 示例3：育儿主题

输入文案片段：
```
孩子发脾气的时候，我以前总是吼回去。
后来我学会了，蹲下来，看着他的眼睛说："妈妈在。"
```

输出画面设计：
```
## 画面 1：吼回去

**场景**：大猫和小猫对峙，气氛紧张
- 大猫表情生气，张嘴吼
- 小猫委屈，眼泪汪汪
- 红色调，紧张氛围

## 画面 2：蹲下来

**场景**：大猫蹲下，和小猫平视
- 大猫表情温柔，伸出手
- 小猫慢慢靠近
- 暖色调，温馨氛围
```

## 注意事项

1. **一致性**：同一主角在不同画面中保持外观一致
2. **对比强化**：用色调、表情、环境对比强化情绪
3. **文字极短**：画面中出现的文字控制在1-2个字
4. **画面填满**：提示词中注明"画面填满整个画布，不留空白"
5. **通用性**：不要硬编码特定场景（如阿里/国企），根据内容自动适配
