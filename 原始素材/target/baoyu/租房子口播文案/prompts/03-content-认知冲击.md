# Prompt

橘猫震惊地看着钥匙串，认知被颠覆。

主角：

- 橘猫表情震惊，眼睛放大
- 嘴巴微张，显得很惊讶
- 姿态僵住，被震撼到

配角：

- 保时捷车主狸花猫手里晃着钥匙串
- 钥匙串上有十把钥匙，闪闪发光
- 表情得意，但不张扬

视觉元素：

- 橘猫头顶浮现问号
- 背景浮现"天之骄子"四个字，但被打了个问号
- 保时捷的虚影在背景中

背景：

- 城市街道，傍晚时分
- 保时捷停在旁边

风格：

- 震撼感，冲击力强
- 暖色调为主，但带一点冷色对比
- 可爱卡通插画风格，线条清晰
- 画面填满整个画布，不留空白
