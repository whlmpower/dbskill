# 口播文案专家组合规则

## 使用说明

当 dbs-script 流程中 Step 2 需要启动专家聊天室时，根据内容类型从下面选择对应的专家组合。

专家组合的目的是**挖掘素材的故事潜力**，不是代替用户写内容。

---

## 专家组合

### 组合A：个人经历故事

**专家**：李诞 + 华杉 + 半佛仙人

**分工**：
- **李诞**：笑点挖掘，把痛苦变成段子，把尴尬变成共鸣
- **华杉**：文案压缩，一句话能说清楚的不用两句话，找超级符号
- **半佛仙人**：节奏把控，前3秒钩子设计，反常识角度切入

**适用场景**：
- 我在XX公司的经历
- 我做了一个什么决定
- 我遇到了一个什么人
- 那天发生了一件什么事

**分析任务**：
1. 这个故事最有冲击力的细节是什么？
2. 前3秒钩子候选（3条）
3. 故事结构：哪个细节放第一，哪个放最后？
4. 哪些细节该砍？砍了反而更好？

---

### 组合B：心理/认知深挖

**专家**：阿德勒 + 契克森米哈赖 + 华杉

**分工**：
- **阿德勒**：心理动机分析，行为背后的真实驱动力
- **契克森米哈赖**：心流状态判断，这个事情值不值得深入
- **华杉**：表达穿透力，把心理学术语翻译成人话

**适用场景**：
- 为什么我总是这样？
- 我发现了自己一个奇怪的模式
- 原来我一直在逃避XX
- 我终于理解了自己为什么会这样

**分析任务**：
1. 行为背后的真实心理动机是什么？
2. 这个洞察能帮到谁？（具体人群画像）
3. 用一句话怎么把这个心理机制说清楚？
4. 有没有类似的经历可以类比？

---

### 组合C：热点评论

**专家**：芒格 + 半佛仙人 + 华杉

**分工**：
- **芒格**：逆向思维，反过来想会怎样？多模型思维分析
- **半佛仙人**：流量逻辑，这个话题能不能火？怎么切入才有差异化？
- **华杉**：观点锐度，一句话能不能让人记住？

**适用场景**：
- XX公司又出事了
- 最近有个新闻大家都在讨论
- 我看到一个热搜，想聊聊
- XX行业要变天了

**分析任务**：
1. 这个热点的核心矛盾是什么？
2. 你的独特视角是什么？（不是新闻复述）
3. 和你的个人经历有什么连接点？
4. 前3秒钩子候选（3条）

---

### 组合D：职场观察

**专家**：芒格 + 阿德勒 + 半佛仙人

**分工**：
- **芒格**：底层逻辑分析，用多元思维模型看职场现象
- **阿德勒**：心理分析，同事/领导行为背后的心理动机
- **半佛仙人**：实战建议，怎么应对？有没有可操作的策略？

**适用场景**：
- 领导说了一句让我很不舒服的话
- 同事做了一个让我很困惑的事
- 公司又发了一个奇葩规定
- 我发现了一个职场潜规则

**分析任务**：
1. 这个现象的底层逻辑是什么？
2. 涉及到哪些心理机制？
3. 有没有可操作的应对策略？
4. 这个观察能帮到谁？

---

## 专家选择的判断逻辑

1. **素材里有具体事件** → 优先看事件类型
   - 事件是个人经历 → 组合A
   - 事件是职场现象 → 组合D
   - 事件是社会热点 → 组合C

2. **素材里主要是观点/感受** → 看观点的指向
   - 指向自己内心 → 组合B
   - 指向外部现象 → 组合C或D

3. **拿不准** → 默认用组合A（个人经历故事）
   - 因为用户的核心优势是「个人经历故事」
   - 个人故事最容易引发共鸣

---

## 专家组合的变体

如果用户明确要求某个专家，或者觉得某个专家不适合，可以调整：

- **替换**：保留组合的核心分工，换一个同类型的专家
- **增减**：可以只用2个专家（简化），也可以加到4个（复杂话题）
- **用户指定**：用户说「我想让XX参与」，直接加入，不需要理由
