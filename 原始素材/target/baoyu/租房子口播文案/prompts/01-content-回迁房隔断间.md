# Prompt

橘猫挤在狭小的回迁房隔断间里，房间被隔板分成多个小空间。

主角：
- 橘猫穿着格子衫，坐在狭小的床上
- 表情疲惫，眼神有些迷茫
- 姿态蜷缩，显得空间很挤

环境：
- 房间非常狭小，床和桌子挤在一起
- 隔板把140平的房子分成5个小房间
- 墙上贴着租房广告，写着"月租1700"
- 窗外是城市夜景，但房间很暗

背景：
- 破旧的回迁房内部，隔音很差
- 能隐约听到隔壁的声音

风格：
- 暗色调，压抑氛围
- 灰蓝色调为主，带一点暖黄灯光
- 可爱卡通插画风格，线条清晰
- 画面填满整个画布，不留空白
