# Prompt

橘猫在国企，同事们在运动，生活轻松。

主角：
- 橘猫穿着休闲装，表情轻松
- 微笑，眼神放松
- 姿态自然，显得很自在

配角：
- 同事们在打篮球、游泳
- 小孩跑进办公室找爸爸
- 大家都很放松，氛围和谐

环境：
- 国企办公区，有运动设施
- 篮球场、游泳池
- 办公室里有小孩在跑

背景：
- 现代化的国企园区
- 绿化很好，环境舒适

风格：
- 暖色调，轻松氛围
- 明亮的绿色和蓝色调
- 可爱卡通插画风格，线条清晰
- 画面填满整个画布，不留空白
